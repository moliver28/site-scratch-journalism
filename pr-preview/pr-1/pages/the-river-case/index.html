The River Argent case

This page is example content generated by the sitefactory journalism template.

What this site demonstrates

  • Profiles at /entities/<id>/ render any YAML field — add a field the theme has never seen (say, favourite_cheese: Gruyere) and it appears on the page with no component changes.
  • The entity graph at /graph/ is compiled from entities/ + edges/ at build time and rendered client-side. Click nodes, filter by kind, or use the list view.
  • Edges carry typed kinds, confidence, and evidence links. A dangling edge reference fails the build — data bugs never render silently.
